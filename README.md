
# OptiCore AI
### Business Intelligence & Financial Scenario Analysis

OptiCore AI is an independently developed business analytics prototype designed to demonstrate how data-driven tools can support operational and financial decision-making.

Built using React Native, Expo, and TypeScript, the application combines financial performance monitoring, scenario simulation, management reporting, and rule-based business recommendations.

## Features

### 1. Business Performance Dashboard
- Monthly revenue and operating cost analysis
- Operating profit and profit margin KPIs
- Visual breakdown of operating expenses

### 2. Financial Scenario Simulator
- Simulate changes in material costs
- Analyze energy cost fluctuations
- Model revenue increases and decreases
- Calculate monthly and annualized profit changes
- Compare alternative business scenarios

### 3. Business Insights Engine
- Rule-based identification of opportunities and risks
- Financial impact interpretation
- Automatically generated recommendations
- High, medium, and low priority classifications

### 4. Management Reporting
- Baseline versus simulated financial performance
- Visual financial comparisons
- Executive summaries
- Copyable management reports
- Browser-based PDF export

## Testing

The application includes automated tests covering:
- Baseline financial calculations
- Positive and negative scenarios
- Profit margin calculations
- Business recommendation rules

Run tests:

```bash
npm install
node --import tsx --test tests/scenario.test.ts
```

Check TypeScript:

```bash
npx tsc --noEmit
```

## Run Locally

Clone the repository and install dependencies.

```bash
npm install
npx expo start --web
```

## Project Purpose

OptiCore AI was developed to explore the intersection of mechanical engineering, operational performance, business analytics, and digital transformation.

The project demonstrates how engineering-based analytical thinking can be applied to financial and operational business problems.

## Limitations

- All company data is synthetic.
- Results are illustrative scenarios, not financial forecasts.
- Recommendations are rule-based, not generated by a large language model.
- PDF export is currently designed for web browsers.
- The financial model does not account for taxes, implementation costs, or secondary operating cost changes.

## Development Status

Functional portfolio MVP. Further improvements are planned.

## Disclaimer

This project is an educational and portfolio demonstration. It is not intended for real-world financial or operational decision-making without additional validation.
